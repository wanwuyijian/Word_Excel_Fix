## 一、自检（自动化）

### 1. 源码自检

```bash
python tests/selftest.py --samples samples --out tests/out
```

| 项目 | 结果 |
| --- | --- |
| 通过 | **284** |
| 失败 | 0 |

覆盖范围：

- 9 个"故意排得乱"的样本（7 个 Word + 2 个 Excel）× 8 套模板 = 72 次优化
- 开关组合：全开 / 全关 / 仅改字体
- 每个产物的以下断言：
  - 处理前后正文文本指纹（w:t / 单元格值）完全一致 → **内容零改动**
  - OOXML 包结构完整、必需部件齐全、关键父元素子节点顺序合规（避免 Word 报"文件已损坏"）
  - 关闭"分页"开关时，正文段落与 Heading 1~3 / Title 样式均无分页设置
  - Excel：表头底色、边框、列宽、打印设置、冻结窗格、页码页脚均已写入
- 非法输入拒绝：缺扩展名、非 OOXML、空 zip、伪造扩展名、`.doc` / `.xls` 老格式
- 输出文件名冲突时自动加 `(2)` / `(3)` 后缀，不覆盖既有文件

## 四、已知限制

1. `.doc` / `.xls` 老二进制格式不支持（会明确提示另存为新格式）。
2. 文档内嵌图片、SmartArt、图表的位置与尺寸不做调整，只处理文字、表格与页面设置。
3. 复杂合并单元格的 Excel 表，自动列宽只做保守估计，个别列可能仍需手工微调。
4. 招标 / 投标模板正文未强制两端对齐（保留原文对齐方式，避免拉伸字间距影响印刷观感）。
5. 拖放功能依赖 `tkinterdnd2`，若运行环境缺少 `tkdnd` 库会退化为「添加文件…」按钮方式（界面会提示）。
