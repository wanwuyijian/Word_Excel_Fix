# 版本更新说明

## 版本号规则

遵循 [语义化版本](https://semver.org/lang/zh-CN/)：`主版本.次版本.修订号`

| 位 | 何时递增 | 举例 |
| --- | --- | --- |
| 主版本 | 不兼容的改动（输出格式变化、命令行参数变更） | 2.0.0 |
| 次版本 | 新增模板 / 新增开关 / 新增文件格式支持 | 1.1.0 |
| 修订号 | 修 bug、调参数、改文案 | 1.0.1 |

版本号**只有一个来源**：`src/wxfixer/version.py` 中的 `APP_VERSION_TUPLE`。
打包脚本读取它生成 Windows 版本资源，界面标题、日志、`--version` 输出也都取自这里，改一处即可。

## 升级流程（发布新版本时按顺序执行）

```bash
# 1. 改版本号
#    编辑 src/wxfixer/version.py：APP_VERSION_TUPLE = (1, 1, 0)
#    同时更新 CHANGELOG.md

# 2. 自检
python tests/selftest.py --samples samples --out tests/out

# 3. 打包（会自动生成版本资源、拷文档到 dist/）
python build_tools/build_exe.py

# 4. 打包后独立自检（把 exe 复制到空目录运行）
Word_Excel_Layout_Optimizer_v1.1.0.exe --selftest

# 5. 提交 + 打标签 + 推送
git add -A
git commit -m "release: v1.1.0"
git tag -a v1.1.0 -m "v1.1.0"
git push origin main --tags

# 6. 在 GitHub 建 Release，上传 dist/ 下的 exe
```

## 打包细节

`build_tools/build_exe.py` 会做这些事：

1. 调 `build_tools/make_version_info.py` 生成 `build/version_info.txt`（Windows 文件属性里的"产品版本/文件版本"）
2. 生成 `Word_Excel_Fix.spec`：
   - `--onefile` + `--noconsole`（无控制台黑窗）
   - 数据文件：`tkinterdnd2` 的 `tkdnd` 原生库、`assets/` 图标
   - `hiddenimports`：`tkinterdnd2`
   - 排除：`numpy` / `pandas` / `matplotlib` / `scipy` / `pytest`（减小体积）
3. 执行 PyInstaller，把 `使用说明.md` / `LICENSE` / `CHANGELOG.md` 拷进 `dist/`

**一个关键陷阱**：onefile 模式下 `sys.executable` 指向临时解包目录，而 `sys.argv[0]` 才是 exe 真实位置。
`src/wxfixer/utils/paths.py` 的 `app_dir()` 冻结时用 `sys.argv[0]`，否则日志和输出目录会落到临时目录里、程序退出即消失。

## 新增一套排版模板

1. 在 `src/wxfixer/templates/library.py` 里照现有写法加一个 `LayoutSpec`，赋给新常量
2. 加入 `ALL_TEMPLATES` 列表（顺序即界面下拉框顺序）
3. 运行自检——所有样本会自动套用新模板跑一遍
4. 用 `build_tools/render_batch.py` 导出 PDF 目检

需要新增模板字段时，在 `src/wxfixer/templates/schema.py` 的 `LayoutSpec` 里加字段并给默认值，
再在 `word_optimizer.py` / `excel_optimizer.py` 里消费它；未给默认值会让其他模板报错。

## 新增一个交互开关

v1.1 起开关由元数据驱动，加一项只需要动两处：

1. `src/wxfixer/templates/schema.py`
   - `ToggleOptions` 加字段（给默认值）
   - `from_dict()` 补上这个 key
   - `TOGGLE_META` 加一条 `(key, 名称, 说明, 组, 默认)`；组用 `"style"`（版式组，受「自动排版」总开关联动）
     或 `"content"`（内容与素材组，独立生效）
2. 引擎里用 `opts.<字段名>` 判断是否生效

界面会自动按 `TOGGLE_META` 渲染复选框、计入摘要文案，无需改 `gui/app.py`。
最后在 `src/wxfixer/selftest.py` 补"开启时确实生效 / 关闭时确实未生效"的断言。

## exe 文件名为什么是纯英文

`build_tools/build_exe.py` 里 `EXE_NAME = f"Word_Excel_Layout_Optimizer_v{APP_VERSION}"`。
GitHub Release 会把中文附件名清洗成 `Word_Excel_._v1.0.0.exe`，导致 README 里的下载链接失效，
所以产物名固定为 ASCII；程序标题、窗口名仍然是中文。

## 验证脚本一览

| 脚本 | 用途 |
| --- | --- |
| `src/main.py --selftest` | 全量回归（样本 × 模板 × 开关），发布前必须 0 失败 |
| `build_tools/_t_toggles.py` | 逐个开关单独开启，断言每个开关都真实生效 |
| `build_tools/_t_e2e.py` | 走 `runner.optimize_file` 真实链路，10 样本 × 8 模板 |
| `build_tools/_t_visual.py` | 导出 PDF 后按像素断言：A4 页面、图片在版心内且居中、页脚页码 |
| `build_tools/_gui_audit.py` | 三种窗口尺寸 × 两种状态下检查控件越界/被压扁 |
| `build_tools/_t_gui.py` | 界面冒烟：切模板、切开关、加文件、截图 |

## 目录约定

| 目录 | 进版本库 | 说明 |
| --- | --- | --- |
| `src/` `build_tools/` `tests/` `samples/` `docs/` `assets/` | ✅ | 源码与资源 |
| `dist/` `build/` `Word_Excel_Fix.spec` | ❌ | 打包产物，每次重建 |
| `data/` `*.log` | ❌ | 运行时日志 |
| `preview/` `tests/preview/` `samples/排版优化输出/` | ❌ | 目检渲染产物 |

exe 不进版本库，通过 GitHub Release 分发。
