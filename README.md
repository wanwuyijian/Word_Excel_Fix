# Word/Excel 排版优化工具（Word & Excel Layout Optimizer）

> 一键把 Word / Excel 调成「能直接交出去」的样子：默认只动排版、不动事实；需要时也能精简文字、适配图片。
> 免安装单文件 exe，复制到任意 Windows 10/11 电脑即可直接使用。

## ✨ 功能概览

| 能力 | 说明 |
| --- | --- |
| 双格式支持 | Word（`.docx` / `.docm`）与 Excel（`.xlsx` / `.xlsm`） |
| 自动识别 | 按扩展名 + 文件内部结构双重判定，无需手动选择文件类型 |
| 8 套排版模板 | 自动识别内容排版 / 发布通知 / 合同 / 招标文件 / 投标文件 / 技术流程 / 技术说明 / 产品介绍 |
| 8 个交互开关 | 版式 5 项 + **自动排版总开关** + **优化文字内容** + **调整图片尺寸**，可任意组合 |
| 内容安全 | 默认逐字零改动：处理前后比对正文文本指纹，文字有差异立即中止；只有显式勾选「优化文字内容」才允许做**只删不增**的精简 |
| 图片适配 | 超出版心的图片等比缩小、过小的图标不放大、自动居中，避免打印被裁切 |
| 批量处理 | 可一次拖入 / 选择多个文件，逐个处理并输出为新文件 |
| 运行留痕 | 操作日志 `operations.log` + 运行日志 `app.log` + 崩溃日志 `crash.log` |
| 免安装 | PyInstaller 单文件 exe，无运行库依赖，可直接拷贝分发 |

## 📦 快速开始

1. 从 [Releases](https://github.com/wanwuyijian/Word_Excel_Fix/releases/latest) 下载 `Word_Excel_Layout_Optimizer_v1.1.0.exe`（单文件，无需安装）。
2. 双击运行（首次启动约 2–5 秒，单文件解包所致，属正常现象）。
3. 把 Word/Excel 文件**拖入窗口**，或点「添加文件…」。
4. 选择排版模板 → 勾选需要的交互选项 → 点「开始优化」。
5. 结果输出到源文件同目录下的 `排版优化输出` 文件夹（可自行更改）。

> 源文件永远不会被修改或覆盖，所有结果都写入新文件。

## 🧩 交互选项说明

选项分成两组：**版式调整**（默认全开，不动任何文字）与**内容与素材**（会改动文字或图片，需自行确认）。

### 版式调整

| 选项 | 勾选（默认） | 取消勾选 |
| --- | --- | --- |
| 自动排版 | 按模板整体重排版式（总开关） | 其余 5 个版式项一并失效，只做文字/图片处理 |
| 修改字体 | 统一正文/标题/表格的字体族（中文+英文） | 保留原文每个文字的字体 |
| 修改字号 | 按模板统一各级字号 | 保留原字号 |
| 修改字体颜色 | 标题着色、正文改黑色 | 保留原字体颜色 |
| 修改背景颜色 | 表头底色、隔行底纹、标题底纹 | 保留原底纹 |
| 调整分页 | 按模板让一级标题另起页、表格不跨页断行 | 完全不动分页设置 |

### 内容与素材

| 选项 | 勾选后做什么 | 默认 |
| --- | --- | --- |
| 优化文字内容 | 按文档类别删除赘语（"众所周知，""值得一提的是"等）、虚化动词（"进行优化"→"优化"）、重复标点与多余空格；**只删不增**，绝不新增任何字 | 关闭 |
| 调整图片尺寸 | 超出可用版心的图片等比缩小、过小的图片不放大、图片段落居中 | 开启 |

> 「优化文字内容」的三重保险：词表白名单 → 单段字符子集校验 → 写盘前全文校验。任一处不通过就整体放弃输出并提示。

## 🖨️ 做了什么（排版层面）

**Word**
- 页面：A4、页边距、页眉页脚距离、纸张方向
- 结构：识别大标题 / 一~四级标题 / 正文 / 列表 / 图表题注，并套用对应标题样式（影响导航窗格和目录）
- 段落：行距、段前段后、首行缩进 2 字符（中文字符单位）、对齐方式、标题与下段同页、标题不被拆行
- 文字：字体族、字号、加粗、颜色（可在选项里关闭）
- 表格：统一边框、表头底色与加粗、跨页重复表头、单元格内容不跨页断开、垂直居中
- 分页：大标题/一级标题另起页、页脚插入页码（第 X 页 / 共 Y 页）

**Excel**
- 表头：底色、加粗、居中、冻结首行
- 数据区：边框（内细外粗）、隔行底纹、数字右对齐 / 文本左对齐 / 自动换行
- 行高列宽：按内容自适应、列宽上限保护
- 打印：A4、页边距、缩放适应一页宽、顶端重复标题行、页脚页码、自动横向（列数较多时）、自动筛选

**图片（Word + Excel）**
- 超出版心宽度的图片等比缩小到版心内，避免打印被裁切
- 小于版心 30% 的图片（图标、小插图）不放大，保持清晰度
- 图片段落居中、去掉首行缩进（否则会整体右移 2 字符）
- 只改显示尺寸，不重采样、不压缩原图像素

**文字（仅勾选「优化文字内容」时）**
- 删句首赘语：众所周知，/ 值得一提的是，/ 综上所述，/ 换言之，…
- 删句中虚词与虚化动词："进行优化"→"优化"，"的过程中"→"过程中"
- 规整标点与空白：重复标点折叠、半角转全角、中文间多余空格
- 全程只删不增：产出文本必须是原文的字符子集，任何"新增字"立即整体放弃输出

## 📝 日志位置

| 日志 | 位置 | 内容 |
| --- | --- | --- |
| `operations.log` | `<exe 所在目录>/data/logs/` | 用户操作记录：添加文件、选择模板、开始/完成、输出路径 |
| `app.log` | 同上 | 运行详情、错误堆栈（5 MB 轮转，保留 5 份） |
| `crash.log` | 同上 | 未捕获异常的完整堆栈 |

若 exe 所在目录不可写（如只读介质、`C:\Program Files`），会自动改用 `%USERPROFILE%\.word_excel_fix\data\logs\`。
界面底部「打开日志目录」按钮可直接定位。

## ❓ 常见问题

**Q：`.doc` / `.xls` 老格式能用吗？**
A：不支持。请先用 Word/Excel 另存为 `.docx` / `.xlsx`（工具会给出明确提示）。老格式是二进制文件，任何"保内容"的排版都无法保证零风险。

**Q：提示"文件正在被占用/无权限"？**
A：请关闭 Word/Excel 中打开的同名文件，或换一个有写权限的输出目录。

**Q：处理后我的目录结构/交叉引用会变吗？**
A：不会。工具只修改字体、字号、颜色、间距、缩进、对齐、边框、底纹、页面与分页设置，不改样式名。
不勾选「优化文字内容」时，文字逐字保留；勾选后也只删赘语，不换词、不调语序。

**Q：「优化文字内容」会不会把意思改掉？**
A：这条是**唯一会动文字**的选项，默认关闭。它只做删减：赘语词表 → 单段字符子集校验 → 写盘前全文校验，
三道关卡任一不通过就整体放弃输出，不会产出"改坏"的文件。首次使用建议先拿副本试跑。

**Q：图片会被压缩变小、打印变糊吗？**
A：不会。只改显示尺寸（EMU），不重采样、不重新编码原图像素；等比缩放，且小于版心 30% 的图不会被放大。

**Q：双击没有任何反应？**
A：查看同目录 `data/logs/crash.log`。首次启动会被杀毒软件扫描而稍慢，属正常现象。
