> 只优化排版，不改动任何文字内容。免安装单文件 exe，复制到任意 Windows 10/11 电脑即可直接使用。

## ✨ 功能概览

| 能力 | 说明 |
| --- | --- |
| 双格式支持 | Word（`.docx` / `.docm`）与 Excel（`.xlsx` / `.xlsm`） |
| 自动识别 | 按扩展名 + 文件内部结构双重判定，无需手动选择文件类型 |
| 内容零改动 | 处理前后对比正文文本指纹，**文字有差异会直接中止**，绝不覆盖源文件 |
| 8 套排版模板 | 自动识别内容排版 / 发布通知 / 合同 / 招标文件 / 投标文件 / 技术流程 / 技术说明 / 产品介绍 |
| 5 个交互开关 | 是否修改字体、字号、字体颜色、背景颜色、是否调整分页 |
| 批量处理 | 可一次拖入 / 选择多个文件，逐个处理并输出为新文件 |
| 运行留痕 | 操作日志 `operations.log` + 运行日志 `app.log` + 崩溃日志 `crash.log` |
| 免安装 | PyInstaller 单文件 exe，无运行库依赖，可直接拷贝分发 |

## 📦 快速开始

1. 从 [Releases](https://github.com/wanwuyijian/Word_Excel_Fix/releases/latest) 下载 `Word_Excel_Layout_Optimizer_v1.0.0.exe`（25.1 MB，单文件，无需安装）。
2. 双击运行（首次启动约 2–5 秒，单文件解包所致，属正常现象）。
3. 把 Word/Excel 文件**拖入窗口**，或点「添加文件…」。
4. 选择排版模板 → 勾选需要的交互选项 → 点「开始排版优化」。
5. 结果输出到源文件同目录下的 `排版优化输出` 文件夹（可自行更改）。

> 源文件永远不会被修改或覆盖，所有结果都写入新文件。

## 🖨️ 做了什么（排版层面）

**Word**
- 页面：A4、页边距、页眉页脚距离、纸张方向
- 结构：识别大标题 / 一~四级标题 / 正文 / 列表 / 图表题注，并套用对应标题样式（影响导航窗格和目录）
- 段落：行距、段前段后、首行缩进 2 字符（中文字符单位）、对齐方式、标题与下段同页、标题不被拆行
- 文字：字体族、字号、加粗、颜色（可在选项里关闭）
- 表格：统一边框、表头底色与加粗、跨页重复表头、单元格内容不跨页断开、垂直居中
- 分页：大标题/一级标题另起页、页脚插入页码（第 X 页 / 共 Y 页）

**Excel**
- 表头：底色、加粗、居中、冻结首行
- 数据区：边框（内细外粗）、隔行底纹、数字右对齐 / 文本左对齐 / 自动换行
- 行高列宽：按内容自适应、列宽上限保护
- 打印：A4、页边距、缩放适应一页宽、顶端重复标题行、页脚页码、自动横向（列数较多时）、自动筛选

## 🛠️ 从源码运行 / 打包

```bash

python src/main.py
```

## 📝 日志位置

| 日志 | 位置 | 内容 |
| --- | --- | --- |
| `operations.log` | `<exe 所在目录>/data/logs/` | 用户操作记录：添加文件、选择模板、开始/完成、输出路径 |
| `app.log` | 同上 | 运行详情、错误堆栈（5 MB 轮转，保留 5 份） |
| `crash.log` | 同上 | 未捕获异常的完整堆栈 |

若 exe 所在目录不可写（如只读介质、`C:\Program Files`），会自动改用 `%USERPROFILE%\.word_excel_fix\data\logs\`。
界面底部「打开日志目录」按钮可直接定位。

## ❓ 常见问题

**Q：`.doc` / `.xls` 老格式能用吗？**
A：不支持。请先用 Word/Excel 另存为 `.docx` / `.xlsx`（工具会给出明确提示）。老格式是二进制文件，任何"保内容"的排版都无法保证零风险。

**Q：提示"文件正在被占用/无权限"？**
A：请关闭 Word/Excel 中打开的同名文件，或换一个有写权限的输出目录。

**Q：处理后我的目录结构/交叉引用会变吗？**
A：不会。工具只修改字体、字号、颜色、间距、缩进、对齐、边框、底纹、页面与分页设置，不增删文字、不修改样式名。

**Q：双击没有任何反应？**
A：查看同目录 `data/logs/crash.log`。首次启动会被杀毒软件扫描而稍慢，属正常现象。
